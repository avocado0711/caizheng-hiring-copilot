# 知识与 RAG 检索

本目录提供公开信息知识库、混合检索和简历实体情报能力。

## 当前能力

- 本地文档知识库
- 中文 BM25 检索
- 岗位、简历实体查询
- 来源、版本、日期和置信度引用
- 比赛用虚构企业 `星桥智能科技` 演示资料

## 重要说明

`knowledge/demo/星桥智能科技.json` 中的公司、组织、论文、专利和业务数字均为虚构比赛资料，与任何现实企业、学校或个人无关。

## 代码

- `store.js`：文档创建、删除和初始化
- `retriever.js`：切分、检索和引用
- `entity-extractor.js`：公司、团队、学校、论文和专利实体抽取
- `value-assessment.js`：经历证据强度评估
- `interview-questions.js`：基于证据缺口的面试追问

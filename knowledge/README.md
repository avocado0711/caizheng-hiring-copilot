# 知识与 RAG 检索

本目录提供公开信息知识库、混合检索和简历实体情报能力。

## 当前能力

- 本地文档知识库
- 中文 BM25 检索
- 岗位、简历实体查询
- 来源、版本、日期和置信度引用
- 144 份公开知识资料和 17 份简历聚合资料，合计 161 份本地知识文档
- 覆盖虚构企业、研发组织、技术架构、岗位标准、论文、专利、高校专业和招聘方法

## 重要说明

`knowledge/demo/星桥智能科技.json` 中的公司、组织、论文、专利和业务数字均为虚构比赛资料，与任何现实企业、学校或个人无关。可用 `npm.cmd run knowledge:build-demo` 确定性重建该资料包。

## 代码

- `store.js`：文档创建、删除和初始化
- `retriever.js`：切分、检索和引用
- `entity-extractor.js`：公司、团队、学校、论文和专利实体抽取
- `value-assessment.js`：经历证据强度评估
- `interview-questions.js`：基于证据缺口的面试追问

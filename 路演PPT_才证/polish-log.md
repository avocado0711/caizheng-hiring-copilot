# 三方向初稿打磨记录

## 方法

- Python 版 Playwright 未安装，设计脚本自动跳过自动体检。
- 按技能降级规则，使用本机 Edge 对 1920×1080 固定画布逐页截图，并逐张目视检查。
- 已检查封面与关键内页各三张，共六张真实渲染图。

## 第一轮观察与调整

1. 瑞士证据网格：右侧证据路径与左侧超大标题形成明确对比；保留大面积留白，避免把技术信息堆成卡片。
2. 午夜技术蓝图：标题与系统地图在两个独立信息区，不依赖装饰渐变；收紧正文宽度，保证暗底上的行宽可读。
3. 人文编辑式信任：衬线标题与档案纸形成项目专属的“可阅读证据”语义；保留正文与档案页之间的呼吸，不增加模板化卡片。
4. 三版骨架分别为左右对照、上下流程、档案清单，没有出现只换颜色的重复外观。
5. 六个候选缩略图均包含真实标题、真实色彩和可辨认的核心素材，没有纯色占位块。

## 当前结论

三版均达到方向选择所需的清晰度，等待用户选择一个方向后制作完整 9+1 页路演稿。

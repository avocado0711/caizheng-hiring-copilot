## Dense Retrieval on Held-out Entities

| 模型 | Recall@1 | Recall@5 | MRR@10 |
| --- | ---: | ---: | ---: |
| BGE-M3 基础模型 | 0.171 | 0.450 | 0.303 |
| LoRA-v4 单独使用 | 0.241 | 0.526 | 0.371 |
| 50% BGE-M3 + 50% LoRA-v4 | 0.249 | 0.535 | 0.381 |

LoRA-v4 在 Top-1、Top-5 和 MRR 上均超过基础模型；正式索引采用 50% 的 LoRA 融合向量。

## End-to-end Retrieval

测试集：1,385 个多正例留出查询，904 个候选文档。

| 检索方案 | Recall@5 | MRR@5 |
| --- | ---: | ---: |
| BM25 | 0.552 | 0.344 |
| Dense | 0.504 | 0.329 |
| BM25 + Dense + RRF | 0.557 | 0.366 |
| RRF + Reranker 权重 1.0 | 0.557 | 0.370 |
| RRF + Reranker 权重 2.0 | 0.550 | 0.367 |

正式链路采用 Top-30 Reranker 候选和权重 `1.0`，在不降低 Recall@5 的情况下提升 MRR。

## Notes

- 全量微调和普通 LoRA 都出现过验证指标与最终检索指标不一致。
- 仅靠 Triplet 准确率会选错模型。
- 当前结果来自合成数据，不能替代真实脱敏 HR 查询评估。
- 学校、公司品牌或论文数量不作为含金量代理，公开资料只用于核对岗位相关背景。
